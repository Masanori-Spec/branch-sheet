書き込んだ言葉を残す。

ノードの ID を照合して、Keyword・Description・Owner を新しいツリーへ。移動、改名、削除、復元をダウンロード前に確認できます。

保存済み .mm＋前回の .xlsx（任意）↓確認 → 新しい .xlsx

1. 保存済みファイルを選ぶ

未選択

プレーン TEXT ノードの .mm。16 MiB 以下。新規作成ではこのファイルだけで開始できます。

任意・新規作成なら不要

注釈を編集して保存した .xlsx。16 MiB 以下。3 シートと予約列を保持してください。

大きなマップは時間とメモリを使います。処理中も中止できます。

ファイルを選ぶか、例を読み込んでください。

2. 変更を確認する

完全一致の ID のみで引き継ぎます。同じ ID を保持するマップのコピーは区別できません。

プレビューは 1 ページ 50 行。長い文字列は省略表示です。「詳細」で全文を確認できます。XLSX と JSON の出力範囲は検索やページ移動で変わりません。

状態 / IDラベル・移動KeywordDescriptionOwner詳細

BranchSheet プレビュー：現在のページのみ。省略された文字列の全文は XLSX を参照してください。

毎回、予約列を作り直す

  1. 初回の XLSX を作り、Calc で 3 つの注釈列を文字列として編集します。
  2. Freeplane の更新後、.mm と前回の XLSX を選びます。行全体の並べ替えは可能です。
  3. 新しい ID は空欄、削除した ID は Removed へ。復元した ID は注釈を回収します。

対応範囲を明確に

元ファイルは変更しません。式の評価、同期、URL 読み込み、アカウント、保存履歴はありません。ノート・装飾は対象外。一般の Excel ブックや Freeplane の全機能には対応しません。

形式・上限・検証について

最大 20,000 件の Active と 20,000 件の Removed、深さ 64、入力各 16 MiB、展開 ZIP 合計 96 MiB、投影テキスト 24 MiB。長い値は別の上限に先に達することがあります。

重複・欠落 ID、別ルート、クローン、暗号化、リッチ・型付き・数式ノード、DTD 宣言、式、リンク、マクロ、未知のシートや列、予約値の編集は拒否します。書式は簡易表に再構築します。

検証対象：Freeplane 1.13.3 と Calc 7.3.7.2 の合成データ。20,000 行のコア更新は約 14 秒、全コア確認の最大メモリは約 472 MiB、Calc の全値確認は約 240 秒でした。端末やデータで変動します。
